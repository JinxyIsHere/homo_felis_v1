# Homo-Felis v1.5: Local Deployment & Environment Setup

Welcome to the offline development repository for the Homo-Felis v1.5 bio-synthetic architecture. This project represents a strictly sandboxed, decentralized, and uncorruptible platform for existential liberation and forward-moving identity continuity.

## Prerequisites
To execute local code parsing, repository audits, and runtime security simulations, ensure your host computer is equipped with the following open-source dependencies:
1. **Python 3.10+** (Ensure "Add Python to PATH" is checked during installation)
2. **Biopython Library** (Install via terminal: `pip install biopython`)
3. **PySerial Driver** (Install via terminal: `pip install pyserial`)

## Local Operational Procedures

### 1. Global Repository Audit
To scan your local folder, verify file-system integrity, and track consolidated base-pair lengths dynamically across all active manifests without cloud dependencies, launch your terminal and run:
```bash
python read_all_blueprint.py
```
*Expected Output:* Verification of a clean, uncorrupted total volume of exactly **3,540 base pairs** distributed across 12 individual `.fasta` manifests.

### 2. Standalone Software Sandbox Simulation
To simulate a background crawler patrol, test the asynchronous Token Bucket focus timers, and view real-time log streaming entirely offline without a connected hardware board, run:
```bash
python hf_local_simulator.py
```
*Handshake Verification:* When prompted by the Human-in-the-Loop (HITL) gate, type `ACTION` and press Enter to verify your conscious focus timeline.

### 3. Integrated Production Interface
To initialize your background crawlers, dump automated telemetry straight to your log files, and activate the live USB serial data gate, connect your Arduino hardware and execute:
```bash
python hf_admin_dashboard.py
```
